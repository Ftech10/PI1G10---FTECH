FTECH 6.0 — COMEÇAR E APRESENTAR

INSTALAÇÃO NOVA
1. Instale Node.js 20+ e MySQL 8+ (ou MariaDB 10.6+).
2. Abra um terminal nesta pasta.
3. Execute: npm ci
4. Execute: npm run setup
5. Abra .env e configure DB_HOST, DB_PORT, DB_USER, DB_PASSWORD e DB_NAME.
6. Execute: npm run db
7. Para apresentação completa em banco novo: npm run seed:presentation
8. Execute: npm start
9. Abra http://localhost:3000
No PowerShell, use npm.cmd no lugar de npm, se necessário.
